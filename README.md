# Prebbleton Peonies — unofficial demo
A static website concept inspired by the public Prebbleton Peonies Instagram profile and its website-coming-soon page.
Pages: home, farm, flowers & visits, weddings, contact.
Motion: petals, animated hero photo, scroll reveal, moving ticker, reading progress, mobile navigation, local-only demo form feedback.
All photography is illustrative stock, not images from the farm. Availability, hours, prices and booking terms are intentionally not invented.
